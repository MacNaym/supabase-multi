# Dove trovo il project_ref?

Apri il progetto nel dashboard Supabase. Il project_ref è l'identificatore del progetto, visibile nell'URL/impostazioni e negli URL del progetto.

Se l'URL API è:
`https://abcdefghijklmnopqrst.supabase.co`

il project_ref è:
`abcdefghijklmnopqrst`

Nel registry inserisci solo il ref, non l'URL completo.
