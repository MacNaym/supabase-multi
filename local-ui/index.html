Discovery PAT model

ACCOUNT
└─ Discovery PAT account-wide
   └─ Projects (account-wide): Read

PROJECT
└─ Operational scoped PAT
   ├─ Project Settings: Read
   ├─ Database: Read-write
   ├─ Migrations: Read-write
   ├─ Logs: Read
   ├─ Advisors: Read
   ├─ API Keys: Read
   └─ Edge Functions: Read-write

Use the account-wide PAT only to discover projects. Use a separate scoped PAT for each project's operational access.
