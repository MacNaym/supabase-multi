# Support

Supabase Multi is currently a pre-release open-source project.

## Before asking for help

Please check:

1. `README.md`
2. `docs/installation.md`
3. `docs/troubleshooting.md`
4. existing GitHub issues

## Good bug reports include

- Supabase Multi version or commit;
- Windows version;
- Python version;
- Supabase CLI version;
- whether the problem affects the dashboard, MCP, CLI, browser routing, or project resolution;
- exact error text with secrets removed;
- reproduction steps.

Never paste PAT values or other credentials into an issue.

## Security reports

Do not use public issues for security vulnerabilities. See `SECURITY.md`.

## Supabase-specific product issues

If the problem is with Supabase itself rather than Supabase Multi, use Supabase's official support and documentation channels.
